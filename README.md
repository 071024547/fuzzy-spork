# 个人项目
 ## 1.分支与合并理解
 分支就是独立开发的一条工作线，可以在不改动主代码的情况下做新功能；合并就是把分支里修改的内容汇总回主版本。
 ## 2.常用命令说明
 cd：切换到指定文件夹；ls：查看当前文件夹里面有什么文件；mkdir：创建新的文件夹；git用来做版本控制，记录每一次文件修改、可以回退到之前版本。
 ## 3.AI给出错误信息记录
 一开始AI告诉我GitHub Pages仓库名字必须和用户名一模一样，查证后发现只有个人主页仓库有这个要求，普通作业项目仓库名称可以自定义。
 ## 4.代码逻辑理解
 1.html文字自动换行：由浏览器根据盒子宽度自动排版，不是固定每行多少个字；
 2.页面居中样式margin:0 auto：只能让有固定宽度的块元素水平居中，如果不设宽度是不会生效的。
